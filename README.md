# linux-tunnel-vpn-iptables-cheatsheet
Command cheatsheet for IPIP, SSH tunnels, OpenVPN, WireGuard, and iptables automation.

## Lab ops

[lab-ops.md](lab-ops.md) is the working sheet. Copy a block, fill in the host, run it. Covers SSH, nginx snippets, iptables add-if-missing, downloads, rsync, Docker, and a Tiny SHell client call.
